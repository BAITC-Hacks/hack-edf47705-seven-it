# Фотографии каталога

В папке также находятся 10 фото продуктов из интернета: авторы и источники
перечислены в [GROCERIES.md](GROCERIES.md). Они используются для демо-магазина.

15 файлов JPEG из изображений, приложенных пользователем 23.09.2026.
Исходные файлы в родительской папке `photo` содержали байты UTF-8 replacement
character вместо бинарных данных JPEG/PNG и не открывались. Для рабочих копий
использованы соответствующие целые JPEG из указанной пользователем папки Telegram
Desktop. Фотографии скопированы без редактирования; водяные знаки сохранены.

Django публикует только эту подпапку через префикс `catalog-photos` в staticfiles.
Не нужно переносить повреждённые файлы из корня `photo` в статические ресурсы.

## Добавить карточки в свою базу

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py import_photo_catalog
```

Команда добавляет отсутствующие карточки по уникальному `photo_key`, повторный
запуск не дублирует и не перезаписывает существующие карточки. Все изменения базы
выполняются одной транзакцией. Цены, остатки, продажи и отзывы не генерируются.
Тексты и источники: `market/photo_catalog.py`.
