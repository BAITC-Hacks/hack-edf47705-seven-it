# Администрирование Foresell

Панель: http://127.0.0.1:8000/admin/. Вход доступен только активным
пользователям с `is_staff=True`. Идентификатор входа — `username`, email
хранится отдельно. Схема авторизации не изменена.

## Запуск в Windows PowerShell

Из корня проекта, с установленными зависимостями в `.venv`:

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver
```

`createsuperuser` запросит имя пользователя, email и пароль. Введите пароль
локально: символы не отображаются. Не передавайте пароль аргументом команды
или через исходники. Django сохранит хеш. Если имя уже занято, команда не
перезаписывает существующий аккаунт. Изменение его прав или пароля требует
отдельного согласования с владельцем.

## Разделы и права

- Пользователи и группы: стандартный Django Admin. Только суперпользователь
  может создавать, изменять и удалять их, в том числе менять пароли и права.
  Staff с `view_user`/`view_group` может просматривать их без хешей паролей.
- Бизнес-профили: разрешения `view_business`, `add_business`, `change_business`.
  Срок подготовки проверяется в пределах 0–52 недель, как в форме загрузки.
  Изменение параметров профиля пересчитывает рекомендации всех его наборов
  существующим сервисом по правилам без обращения к платному API.
- Наборы данных и рекомендации: `view_dataset` для просмотра,
  `change_dataset` для переименования и массового пересчёта рекомендаций.
  Рекомендации и связь с бизнесом не редактируются вручную.
- История продаж и бронирований: просмотр по `view_record` (или
  `change_record` по стандартной семантике Django). Добавление и изменение
  через админку запрещены; используется существующий импорт CSV.

Удаление бизнес-профилей, наборов и записей через админку, включая массовые
действия, запрещено даже суперпользователю: в проекте нет механизма отмены
учётных операций. Исправленную историю можно импортировать новым набором.
Ссылки на связанные записи не отменяют проверку прав на целевую модель.
Изменения и пересчёты сохраняются в стандартном журнале Django Admin.

Команд, задач, рейтинга готовности, предложений команд, каталога товаров,
склада и финансовых проводок в этой версии проекта нет. Рекомендации спроса
в Dataset не являются предложениями студенческих команд.

Публичные страницы загрузки, демо, отчётов и рекомендаций сохраняют прежнее
поведение без авторизации. Права Django Admin не распространяются на эти
публичные маршруты; разграничение доступа владельцев бизнеса потребует
отдельной доработки модели владения и представлений.
