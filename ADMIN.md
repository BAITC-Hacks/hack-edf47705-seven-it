# Администрирование Foresell

## Вход пользователей и администратора

На основном сайте кнопка «Войти» открывает `/login/`. Продавцы и покупатели
входят по email и паролю и попадают в свой профиль `/account/`. Их группы
видны в админке в разделе «Пользователи», колонка «Роли / группы»; доступен
фильтр по группам. Эти пользователи не получают `is_staff` или `is_superuser`.

Ссылка «Админ» открывает отдельный вход `/admin/`. Основная форма входа
не принимает аккаунты staff/superuser. Сессии разделены: `foresell_session`
для сайта и `foresell_admin_session` с путём `/admin/` для админки. Можно
одновременно войти как покупатель и администратор; выход из одного аккаунта
не завершает другую сессию. После обновления со старого `sessionid` нужно
войти заново. Пароли и права существующих пользователей не меняются.

Профили показывают данные текущего пользователя и его роль из `market.Profile`.
Из кабинета доступны каталог, личные финансы и товары продавца. `/market/login/`
использует ту же форму, что `/login/`, включая запрет входа администратора.
Для аккаунтов, зарегистрированных без email, поддерживается вход по логину.

Панель: http://127.0.0.1:8000/admin/. Вход доступен только активным
пользователям с `is_staff=True`. Идентификатор входа — `username`, email
хранится отдельно. Схема авторизации не изменена.

Панель использует логотип Foresell и тот же переключатель светлой и тёмной
темы, что и основной сайт. Выбор темы сохраняется при переходе между ними.
На основном сайте есть отдельная ссылка «Админ»; пользовательская сессия
не подставляет в неё аккаунт покупателя или продавца.
В списке и карточке набора данных есть ссылка «Открыть прогноз»; примечание
к рекомендациям помогает понять, почему использован расчёт по правилам.

## Запуск в Windows PowerShell

Из корня проекта, с установленными зависимостями в `.venv`:

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver
```

`createsuperuser` запросит имя пользователя, email и пароль. Введите пароль
локально: символы не отображаются. Не передавайте пароль аргументом команды
или через исходники. Django сохранит хеш. Если имя уже занято, команда не
перезаписывает существующий аккаунт. Изменение его прав или пароля требует
отдельного согласования с владельцем.

## Разделы и права

- Пользователи и группы: стандартный Django Admin. Только суперпользователь
  может создавать, изменять и удалять их, в том числе менять пароли и права.
  Staff с `view_user`/`view_group` может просматривать их без хешей паролей.
- Бизнес-профили: разрешения `view_business`, `add_business`, `change_business`.
  Срок подготовки проверяется в пределах 0–52 недель, как в форме загрузки.
  Изменение параметров профиля пересчитывает рекомендации всех его наборов
  существующим сервисом по правилам без обращения к платному API.
- Наборы данных и рекомендации: `view_dataset` для просмотра,
  `change_dataset` для переименования и массового пересчёта рекомендаций.
  Рекомендации и связь с бизнесом не редактируются вручную.
- История продаж и бронирований: просмотр по `view_record` (или
  `change_record` по стандартной семантике Django). Добавление и изменение
  через админку запрещены; используется импорт CSV или XLSX.

Удаление бизнес-профилей, наборов и записей через админку, включая массовые
действия, запрещено даже суперпользователю: в проекте нет механизма отмены
учётных операций. Исправленную историю можно импортировать новым набором.
Ссылки на связанные записи не отменяют проверку прав на целевую модель.
Изменения и пересчёты сохраняются в стандартном журнале Django Admin.

Каталог поддерживает остатки товаров и историю цен/продаж, а раздел личных
финансов — учёт доходов и расходов. Команды, учебные задачи и предложения
студенческих команд пока не реализованы.

Демо-прогнозы открыты. Пользовательские отчёты доступны владельцу аккаунта,
создавшей их гостевой сессии или сотруднику панели. Старые отчёты сохранены,
но не публикуются автоматически: суперпользователь может назначить владельца
бизнес-профилю. Обычный сотрудник не может менять владельцев профилей.

Новый раздел каталога содержит товары, историю цен, профили и модерацию отзывов.
Личные финансы и чат доступны только владельцу через обычный сайт и не представлены
в админ-панели. Подробности новых функций: [MARKET.md](MARKET.md).
